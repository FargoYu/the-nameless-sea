## 发布到 GitHub Pages

1. 创建一个公开仓库，例如 `the-nameless-sea`。
2. 将这里解压出的 `index.html`、`README.md`、`cover.jpg`、`.nojekyll` 上传到仓库根目录。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
6. 等待 GitHub Pages 部署完成，然后在 Pages 设置中打开网站地址。
